# Liminal Lacuna of Morpheus

`Liminal Lacuna of Morpheus`는 MacBook의 노치 때문에 보이지 않는 메뉴 막대 항목을 별도의 가로 패널에서 사용할 수 있게 해 주는 macOS 유틸리티입니다.

대표 아이콘을 누르면 노치에 가려진 항목만 아래쪽 패널에 표시됩니다. 화면에 정상적으로 보이는 Wi‑Fi, Bluetooth, 배터리 등의 항목은 기존 메뉴 막대에 그대로 남습니다.

## 주요 기능

- 메뉴 막대에 상주하는 대표 아이콘
- 아래 방향으로 열리는 가변 폭 단일 행 패널
- 실행 중인 앱의 `AXExtrasMenuBar` 항목 자동 탐색
- Window Server 상태를 기준으로 노치에 가려진 항목만 선별
- 메뉴 막대에 실제로 렌더링된 이미지와 원래 항목 폭 유지
- 왼쪽 클릭 시 원본의 `AXPress` 동작 전달
- 오른쪽 클릭 시 원본의 `AXShowMenu` 동작 전달
- 패널 바깥을 클릭하면 자동으로 닫힘

## 요구 사항

- macOS 14 이상
- Swift 6.2를 지원하는 Xcode Command Line Tools

## 빌드 및 실행

```sh
./scripts/build-app.sh
open "dist/Liminal Lacuna.app"
```

## 권한

처음 실행할 때 **시스템 설정 > 개인정보 보호 및 보안**에서 다음 권한을 허용해야 합니다.

- **손쉬운 사용**: 원본 메뉴 막대 항목 탐색 및 동작 전달
- **화면 및 시스템 오디오 녹화**: 메뉴 막대에 실제로 렌더링된 이미지 캡처

권한을 허용한 뒤 앱을 다시 실행해 주세요. 대표 아이콘의 오른쪽 클릭 메뉴에서 각 권한 설정을 바로 열 수 있습니다.

로컬 패키징 스크립트는 재빌드 후에도 권한이 유지되도록 번들 ID 기반의 안정적인 지정 요구사항으로 앱을 임시 서명합니다.
