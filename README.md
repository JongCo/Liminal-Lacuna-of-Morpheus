# Liminal Lacuna

macOS 메뉴 막대의 대표 아이콘을 누르면 아래쪽에 가변 폭 단일 행 패널을 표시하고, 발견한 원본 메뉴 막대 항목의 동작을 전달하는 프로토타입입니다.

## 현재 구현

- 메뉴 막대 대표 아이콘
- 아래 방향으로 열리는 가변 폭 패널
- 아이콘 한 줄 가로 배치
- 실행 중인 앱의 `AXExtrasMenuBar` 항목 자동 탐색
- 메뉴 막대에 실제로 그려진 항목 이미지를 캡처해 원래 폭으로 표시
- 자연 상태에서도 노치에 가려져 Window Server가 표시하지 못한 항목만 패널에 포함
- 접근성 `AXPress`를 통한 원본 기본 동작 전달
- 패널 아이콘 우클릭 시 원본의 `AXShowMenu` 보조 동작 전달
- 바깥 클릭으로 패널 닫기
- 정상적으로 표시되는 원본 메뉴 막대 항목은 그대로 유지

## 실행

```sh
./scripts/build-app.sh
open "dist/Liminal Lacuna.app"
```

처음 실행할 때 시스템 설정의 **개인정보 보호 및 보안**에서 다음 두 권한을 허용해야 합니다.

- **손쉬운 사용**: 원본 메뉴 막대 항목 탐색 및 동작 전달
- **화면 및 시스템 오디오 녹화**: 메뉴 막대에 실제로 그려진 아이콘 캡처

권한을 허용한 뒤 앱을 다시 실행해 주세요.

로컬 패키징 스크립트는 재빌드 후에도 손쉬운 사용 권한의 앱 식별자가 유지되도록 번들 ID 기반 지정 요구사항으로 임시 서명합니다. 기존 방식으로 만든 빌드에 권한을 부여했다면 해당 항목을 시스템 설정에서 한 번 제거한 뒤 새 빌드를 다시 추가해야 합니다.

## 다음 기술 검증

노치 뒤에 있는 원본 항목은 `AXPress`만으로 메뉴 위치를 보장할 수 없습니다. 다음 단계는 해당 항목 하나를 대표 아이콘 옆의 임시 슬롯으로 이동하고, 실제 마우스 클릭을 보낸 뒤 메뉴가 닫히면 원래 위치로 복원하는 것입니다.
